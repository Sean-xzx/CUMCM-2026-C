# 问题二运行说明

## 两份主文件

- `问题二_逐日滚动预测与CCP优化.ipynb`：代码运行版，按“数据审计—1月选模—残差经验分布—CCP—事后比较”依次执行。
- `问题二_论文建模思路.md`：论文写作版，包含完整符号、公式、模型、结果与限制。

## 运行方法

1. 保证本目录中的3个CSV与 `q2_pipeline.py` 不改名。
2. 缺少依赖时运行：`python -m pip install -r requirements.txt`。
3. 打开 Notebook，执行“Restart Kernel and Run All”。

关键输出：

- `一月模型评价.csv`：只基于 1 月 15—31 日滚动回测，作为模型选择证据。
- `2至12月_事后模型评价.csv`：以1月为初始训练期、每日吸收前一天新真值后的样本外预测评价，只作事后观看。
- `2至12月_CCP费用对比.csv`：固定模型与参数后，对 2—12 月的平行费用比较。
- `模型评价与费用对比.png`：一月选模与事后费用的汇总图。
- `一月EW_EWMA净负荷残差分布.png`：经验分位数余量的残差分布与Q–Q诊断图。
- `数据质量摘要.csv`：时间边界、矩阵维度与缺失检查。

信息边界：每天0:00只用前一天及更早的真实值；当天144个时段不进行日内更新。每过完一天，该日真值立即成为新已知数据：EW/EWMA更新窗口，岭回归按用户原Notebook的规则更新至多最近42天窗口并每日重拟合（`alpha=1.0`、原特征），XGBoost每日扩展重拟合，GRU每日继续训练。

储能初始化：以2025年2月1日为正式滚动规划起点；因缺少1月实际调度轨迹，将该日0:00的SOC初始化为6000 kWh。此后SOC按日连续传递，不在每天0:00重置。
